# HiddenRecorder 0.1.0 — Preview

First versioned portable release for Windows 10 22H2 and Windows 11 x64.

## Features

- Live camera preview and microphone level, with a configurable sound threshold.
- Sound-triggered MP4 video with audio and pre-recording to include the start of an event.
- A configurable stop delay in minutes; each qualifying sound extends recording.
- Automatic settings saving and configurable video/audio quality.
- Daily recording folders, recreated when needed, and recovery of unfinished recordings.
- System tray controls and reopening the existing window by launching the EXE again.
- English interface and a portable folder containing the required application runtimes.

## Download and run

Download `HiddenRecorder-0.1.0-win-x64.zip` from this release, extract all files, and run `HiddenRecorder.App.exe`. Choose your camera, microphone, and output folder, then click **Start monitoring**. Closing the window hides it; choose **Exit** to stop the app completely.

`HiddenRecorder-0.1.0-win-x64.zip.sha256` contains the archive checksum. The ZIP is the runnable application; GitHub's automatically generated source archives are for source code.

## Preview limitations

This release has passed automated application-rule tests and short camera/audio recording, decoding, seeking, folder-recreation, and window-restoration checks on the development PC. Clean Windows 10/11 testing, an eight-hour stability run, physical power-loss testing, and direct VLC/Windows Media Player acceptance remain outstanding. See [validation results](https://github.com/Gaikov/HiddenRecorder/blob/v0.1.0/VALIDATION.md) for details.

Settings and recordings stay in the current Windows user profile or the selected output folder; they are not included in the download.
