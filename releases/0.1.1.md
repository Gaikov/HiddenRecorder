# HiddenRecorder 0.1.1 — Preview

Fixes camera and microphone recovery after the computer wakes from sleep.

## Changes

- Automatically reconnects the camera and microphone after waking, restoring preview or monitoring according to the mode used before sleep.
- Retries reconnection while device drivers become available. If recovery fails, the app displays instructions for retrying manually.
- Attempts to finish the current recording before sleep. After waking, a new qualifying sound starts a new file; old buffered footage and timers are cleared.
- Cancels pending recovery when the app stops or exits, and handles repeated sleep/resume notifications.

## Download and update

Download `HiddenRecorder-0.1.1-win-x64.zip`, extract the entire archive into a new folder, and run `HiddenRecorder.App.exe`. Exit the previous version before launching this one. Existing settings and recordings are preserved; they are not included in the archive.

The portable package includes the required application runtimes for Windows 10 22H2 / Windows 11 x64. Windows N requires Media Feature Pack. No application installation is required. The `.zip.sha256` file contains the archive checksum. GitHub's source archives are not runnable application packages.

## Validation and preview limitations

All 47 automated tests passed. Application suspend/resume operations were exercised with synthetic media and a real camera/microphone, including repeated preview restarts, restored monitoring, and finalized recordings before and after recovery. Resulting MP4 files passed decoding, index, and seeking checks.

These checks invoked the application lifecycle directly. Actual lid-close, Windows sleep/hibernation, Modern Standby, and post-sleep preview rendering still require testing on the target laptop. Clean-machine and extended stability acceptance also remain outstanding. See the [validation record](https://github.com/Gaikov/HiddenRecorder/blob/v0.1.1/VALIDATION.md).
